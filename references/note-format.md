# Douyin Note Format Reference

## For Short Content (< 100 chars)

For quotes, aphorisms, or very short insights:

```markdown
# {主题词} · 抖音笔记

> {原始内容}

---

## 来源

抖音视频
```

## For Long Content (100+ chars)

For knowledge sharing, commentary, or deep dives:

```markdown
# {主题词} · 抖音笔记

> {一句话概括核心观点}
> 来源：抖音视频

---

## 核心内容

**{核心命题}**

- {提炼要点1}
- {提炼要点2}
- {提炼要点3}

---

## 金句

> "{视频原话金句}"

---

## 下一条线索

[[相关笔记]]
```

## Conventions

- No "AI" or "generated" in the note body
- Use `·` (middle dot) in titles
- `---` to separate sections
- Wikilinks for related notes
- Keep it concise — the note is a digest, not a transcript
